About the project

Built to make everyday spending easier to understand.

What it does

Practical expense control

Record daily spending, edit mistakes, filter older entries, and view category or monthly patterns without needing a database setup.

Privacy

Saved on this browser

Login details and expenses are stored locally in the browser for this student project. Logout closes the session but keeps records available for the next login.

Login first flow The tracker opens only after login, with logout available from every main page.
Editable records Correct expense details without deleting and re-entering the item.
Useful filters Search by description, category, and date range when records grow.
Visual summaries Category chart, monthly spending bars, totals, averages, and largest expense.
