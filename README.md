````md
# Expense Tracker 💰

A modern and responsive Expense Tracker Web Application built using HTML, CSS, and JavaScript. This project helps users manage daily expenses, track spending habits, and visualize expenses using graphs.

---

## 🚀 Live Demo

https://your-render-link.onrender.com

---

## 📌 Features

- ➕ Add new expenses
- ✏️ Edit expense records
- ❌ Delete expenses
- 🔍 Search and filter expenses
- 📅 Filter by date range
- 📊 Expense graph visualization
- 💱 Multiple currency support
- 📱 Fully responsive design
- 🎨 Modern dashboard UI
- 💾 Data stored using Local Storage

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js
````

2. Open Render Dashboard
3. Select **New Static Site**
4. Connect GitHub repository
5. Set Publish Directory:

```bash
.
```
